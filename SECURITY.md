# Security Policy

## Supported Versions

Only the latest released minor version of PanzerGeneral receives security fixes.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in PanzerGeneral, please report it
privately rather than opening a public issue.

- Email: **jakubvonsyrek@gmail.com**
- Subject line: `[security] PanzerGeneral - <short description>`

Please include:

- A clear description of the issue and its impact.
- Steps to reproduce, ideally with a minimal proof of concept.
- The affected version (or commit SHA) and the environment you observed it on.

You can expect:

- An acknowledgement within 72 hours.
- A status update within 7 days.
- Coordinated disclosure once a fix is available.

Thank you for helping keep PanzerGeneral and its users safe.
